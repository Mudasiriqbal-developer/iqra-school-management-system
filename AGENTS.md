# Agent Rules & Guidelines for Iqra School Management System

## Documentation Rule: Synchronous README Maintenance
Whenever any of the following changes occur in the project:
1. **New dependencies or packages** are installed in either `backend/` or `frontend/`.
2. **New features, modules, pages, or modals** are created or refactored.
3. **Database schemas / models** are added, modified, or extended in `backend/models/`.
4. **New API endpoints or route changes** are introduced in `backend/routes/`.
5. **Environment variables** (`.env`) are introduced, altered, or required.
6. **Architecture or role workflows** (Admin, Teacher, Student) are updated.

**Instruction for Agent:**
- You MUST immediately update `README.md` at the project root to reflect those changes.
- Ensure the 'What, Where & Why' tables, API endpoint lists, features, and setup sections accurately document the new additions so the developer always has a complete and clear understanding of the codebase.
